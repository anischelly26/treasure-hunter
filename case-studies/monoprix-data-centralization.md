# MISSION_03 — Sales Data Centralization

**Context:** Monoprix Headquarters, Tunis  
**Type:** Data Management Internship, July 2024

## Problem

Daily sales information coming from multiple stores needed to be collected in a more structured, centralized way so that it could be accessed, analyzed and managed more efficiently.

## Work completed

The internship focused on building a centralized database workflow for store sales information and reducing repetitive manual data handling.

Key tasks included:

- designing a centralized sales-data structure
- importing external-file data into the database with Python
- working with MySQL / SQL Server concepts and tooling
- organizing product, store, time and transaction information
- reducing redundancy in stored data
- improving data accessibility and query efficiency
- considering integrity and consistency during import and storage

## Engineering focus

A major challenge was moving external-file data into the correct database structure and connecting the Python workflow to the database environment. The result was a practical data-import and centralization pipeline rather than a purely theoretical database exercise.

## Stack

`Python` `MySQL` `SQL Server` `XAMPP` `Data Centralization` `Automation`
