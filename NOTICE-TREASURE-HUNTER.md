# Treasure Hunter source attribution

The playable browser adaptation in this portfolio is based on the public team repository:

- Source mirror: https://github.com/adam12bT/Treasure-Hunter
- Original implementation: C + SDL2
- Browser adaptation in this portfolio: `treasure-browser.js`

The adaptation reuses the original level-map data and references the public game assets at runtime. The browser physics/rendering layer is a JavaScript adaptation rather than a claim that the original SDL2 executable is running in the browser.

The source repository includes an MIT license notice credited to Amine Ben Hassouna. That notice remains available in the original repository and should be preserved with substantial reuse of the source.
